# Grok Slow Downloader（試作版）

Chrome拡張 Manifest V3。画像・動画を同時に1件だけ保存します。完了後は最低5秒待ちます（Chromeの休止やアラームにより長くなる場合あり）。外部サーバーへの送信はありません。

## インストール
1. GitHubの「Code → Download ZIP」で取得し、ZIPを展開。
2. Chromeで `chrome://extensions` を開き「デベロッパーモード」をON。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開した `1-main` フォルダ（manifest.jsonがあるフォルダ）を選択。
4. GrokにログインしてImagineの自分の履歴を開く。
5. 拡張の「今の画面を収集」で登録数を確認し、まず少数を「保存開始／再開」で保存。保存ファイルの内容を確認。
6. 続ける場合は「自動スクロール収集」。保存開始も押すと収集しながら順番に保存。

Chrome設定の「ダウンロード前に各ファイルの保存場所を確認する」がONならOFFにすると連続保存できます。保存先は通常のダウンロードフォルダ内のGrokImagineです。

## 停止・再開
「停止」は収集と新規ダウンロード開始を止めます。進行中の1件はそのまま完了させます。再開ボタンで待機分から続行。Chrome再起動後は自動で新規保存せず、再開ボタンを押してください。ダウンロード履歴から進行中だった処理の結果を照合します。URLごとの完了記録は拡張内に保存されます。拡張削除、プロファイル変更、拡張データ消去で記録は失われます。保存済みファイルを手動削除しても完了記録は残ります。

失敗は最大3回まで自動で再試行。上限後は「失敗を再試行対象に」→「保存開始／再開」。401/403や期限切れURLの場合はログイン状態を確認し、履歴を読み込み直してください。別URLは別項目として登録されます。

## 対応範囲・制約
Grok実機未検証の試作版です。非公開APIは推測して実装していません。現在DOMにある画像・動画URLを収集し、自動スクロールで次の読込みを試みます。履歴タブは開いたままにしてください。画面変更、別アカウント切替前には停止してください。
全履歴の取得完了判定はありません。追加数が0でも全件取得とは限りません。自動収集は手動停止してください。再起動後のスクロール位置は復元しませんが、登録済みダウンロード待ちは保持します。
動画のサムネイルは画像として保存される場合があります。動画本体がDOMにない場合は取得できません。blob URL、HLS、他ドメインのCDN、背景画像には未対応。画面のプレビュー画質が保存される場合があります。画像サイズフィルターで小さい生成画像が除外されることもあります。
重複判定は完全なURL単位です。署名や画質パラメーターが変わると同じ作品でも別ファイルになります。保存ファイル名はURLのSHA-256。作品IDベースでの重複防止、全履歴取得、原本動画取得は実際の通信仕様を確認した追加対応が必要です。

権限: downloads（保存・結果照合）、storage/unlimitedStorage（大量の待機記録）、alarms（休止後の処理再開）、scripting/activeTab/grok.com（履歴画面の読取り・スクロール）。他のサイトのダウンロード履歴は処理しません。

## 検証
